# Laboratório IA

Ambiente de testes para agentes de programação com GitHub Codespaces e modelos gratuitos.

## Segurança
- Não salvar chaves de API, senhas ou dados de clientes neste repositório.
- Testar novos agentes primeiro neste laboratório, antes de conectá-los aos projetos existentes.

## Próximo passo
Abrir este repositório em **Code → Codespaces → Create codespace on main**.
